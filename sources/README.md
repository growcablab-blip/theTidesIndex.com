# Source Files

Place private research source files into the categorized folders here.

Recommended approach:
- preserve original files
- optionally create a renamed duplicate using `docs/SOURCE_FILE_RENAME_MAP.csv`
- never put source books under a public web/static directory
- never publish full copyrighted source PDFs without permission

QC states in `SOURCE_MANIFEST.json`:
- `usable`
- `incomplete`
- `replace`
- `pending`
- `exclude`

Files marked `replace` are not authoritative inputs.
