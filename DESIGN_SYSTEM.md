# DESIGN SYSTEM BRIEF — The Tides Index

## Brand character

The Tides Index should feel like a modern medical/scientific reference:
- calm
- precise
- independent
- intelligent
- accessible
- highly legible

It should not resemble:
- a peptide shop
- a bodybuilding brand
- a luxury wellness clinic
- a crypto dashboard
- a beach/tropical site

The name “Tides” should appear through subtle rhythm, layered curves, information flow, and motion—not literal waves everywhere.

## Working visual palette

Use as a starting point; refine after real screens exist.

- Ink: `#0B1F2A`
- Deep Tide: `#123F4A`
- Tide Teal: `#1F6B73`
- Sea Glass: `#DCEDEF`
- Mist: `#F2F7F7`
- Warm White: `#FBFCFA`
- Slate: `#66747B`
- Rule/Border: `#D6E0E2`

Evidence/status colors should be restrained and accessible. Never rely on color alone.

## Typography

Choose highly legible, web-safe/open licensed fonts.
- Editorial/scientific headline: refined serif or humanist sans
- UI/body: clean sans
- Data/tables: sans with strong numeral legibility

Priorities:
- readability
- print rendering
- medical credibility
- excellent table density

## Layout

Desktop:
- comfortable max reading width
- sticky in-page contents on long practitioner pages
- persistent search
- clear simple/practitioner switch

Mobile:
- no horizontal data-table traps
- cards may collapse evidence metadata
- citations remain accessible
- protocol detail remains source-labeled

## Page hierarchy for a peptide

1. Name + aliases
2. One-sentence orientation
3. Evidence snapshot
4. Simple/practitioner toggle
5. What it is
6. Mechanism/targets
7. Research applications
8. Human evidence
9. Preclinical evidence
10. Administration routes
11. PK/formulation
12. Safety/limitations
13. Regulatory/development status
14. Source-specific protocols (practitioner)
15. Disagreements/unknowns
16. References
17. Last reviewed/version

## Reusable figure families

1. amino acid → peptide → protein
2. receptor → signaling cascade
3. biological pathway
4. body-system map
5. administration-route anatomy
6. synthesis/manufacturing flow
7. analytical testing / COA explainer
8. evidence ladder
9. protocol comparison
10. provenance chain

Text-critical figures should be SVG/vector.

## Evidence components

Every evidence card should show, as applicable:
- evidence type
- population/model
- route
- source
- year
- outcome summary
- limitations
- verification state

## Protocol component

Never show a floating dose with no context.

Header:
`Source-reported protocol`

Then:
- Source
- Context
- Population/model
- Route
- Amount as reported
- Frequency
- Duration
- Monitoring
- Cautions
- Evidence type
- Verification state

## Patient mode

Use:
- more white space
- shorter paragraphs
- larger diagrams
- question-and-answer framing
- evidence explanations

Avoid:
- dosing tables
- excessive abbreviations
- dense pathway notation
- clinical shorthand without definitions

## Print/PDF

Web pages and publications should have dedicated print styles.
PDF output should look like a real publication, not a browser screenshot.
