# BRAND BRIEF — The Tides Index

## Name
**The Tides Index**

## Domain
**thetidesindex.com**

## Descriptor
**Independent peptide science & clinical reference.**

## Brand promise
Make complex peptide information easier to understand without hiding uncertainty or losing the source trail.

## Personality
- precise
- independent
- calm
- curious
- modern
- clinically literate
- never promotional

## Voice
Prefer:
- “Human evidence is limited.”
- “This route has been reported in…”
- “LaValle describes…”
- “In this animal model…”
- “Regulatory status checked on [date].”
- “Evidence remains uncertain.”

Avoid:
- “miracle”
- “game-changing”
- “proven peptide”
- “ultimate stack”
- “guaranteed”
- “anti-aging cure”

## Primary navigation
Learn / Science / Peptides / Evidence / Protocols / Quality / Sources

## Brand test
A physician should be comfortable sending the URL to a patient.
A patient should not mistake the site for an online peptide shop.
