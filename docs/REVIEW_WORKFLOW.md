# REVIEW WORKFLOW

## Roles

### Editor
Extracts and structures content.

### Scientific reviewer
Checks chemistry, biology, mechanism, evidence interpretation, source fidelity.

### Clinical reviewer
Checks clinical relevance, population/context, safety wording, protocol framing, patient/practitioner separation.

### Compliance reviewer
Checks regulatory claims, approved/investigational framing, patient-facing boundaries, disclosures.

### Admin
Manages permissions and release operations.

## Suggested gates

### Low-risk educational concept
Editor -> scientific review -> publish

### Peptide mechanism/evidence summary
Editor -> source check -> scientific review -> publish

### Safety or regulatory claim
Editor -> source check -> scientific + compliance review -> publish

### Protocol
Editor -> source check -> primary verification where applicable -> scientific + clinical + compliance review -> publish

## Staleness

Suggested internal review clocks:
- foundational chemistry: 24–36 months
- general quality science: 12–24 months
- individual peptide evidence: 6–12 months
- investigational clinical programs: 3–6 months
- regulatory/approval status: 1–3 months or event-driven

These are workflow defaults, not claims about clinical practice.
