# Starter schema (superseded)

These are the two SQL files shipped in the original handoff package as
`supabase/migrations/`. They were explicitly described as "a starter
architecture for Claude Code to review/refine before applying".

They are retained here for reference only and are **not** applied. The live
schema is generated from `db/schema/*.ts` into `db/migrations/`.

Material differences are documented in `docs/IMPLEMENTATION_RECORD.md`.
